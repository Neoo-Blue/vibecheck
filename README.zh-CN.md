# Vibecheck · 读空气

[English](README.md) · **中文**

**Vibe check before you reply.** 一个 Android 无障碍 + 悬浮窗工具：在聊天应用的对话页上读取屏幕上可见的消息，
调用 TypeSafe 的 System One 模型 Jev 做判断，然后以一个小气泡挂在屏幕边缘；
点气泡展开解读卡片。完全在手机上运行，不需要电脑、不需要 root、不需要连 adb。

支持的应用（设置里勾选）：微信、QQ、Soul、LINE、KakaoTalk、WhatsApp、Telegram、Messenger、
Instagram、Google Messages（短信 / RCS）、三星信息、Signal、Snapchat、Viber、X、Teams，
以及任何「对方靠左、自己靠右」布局的聊天应用（填包名即可）。Discord / Slack 所有消息都靠左，
分不出你我，所以不在列表里。

## 判断分两步

每来一条新消息先做一次**分诊**：

| id | 类型 | 问什么 |
|---|---|---|
| `situation` | choice | 你们是什么关系：恋人 / 暧昧 / 朋友 / 家人 / 同事 / 客户 / 陌生人 / 客服。只在还不知道时才问（见「Ta 是你的什么人」） |
| `intent` | choice | 当前真实意图 |
| `danger` | score | 翻车风险 x / 6 |
| `urgency` | noul | 需要马上回吗 |

闲聊、接梗、单纯同步信息，到此为止：气泡上一个点，卡片一行字。值得细看的才问第二步，
而且**问什么取决于场合**，所以工作聊天和第一次跟陌生人聊，卡片上的标题不一样：

| 场合 | 第二步问的 |
|---|---|
| 同事 / 客户 / 客服 | 对方在要什么、时间压力、顺着回会不会等于答应了、最佳动作 |
| 陌生人 | 对方兴趣、该我推进吗、话题怎么走、最佳动作 |
| 朋友 / 家人 | 对方心情、现在需要什么、最佳动作 |
| 恋人 / 暧昧 | 真的在说字面意思吗、现在需要什么、最佳动作 |

Jev 只给判断和概率，不写话术。卡片底部的「建议动作」是代码按 `danger` 算出来的。

Jev 有两条路，请求和答案一模一样：TypeSafe 自己的接口（`api.typesafe.ai`，默认），
或 OpenRouter 的 decisions 接口（`openrouter.ai/api/alpha/decisions`，模型 `~typesafe/jev-latest`）。
应用界面在最上面可切换中文 / English；问题集始终是中文的，因为选项原文就是每个人学习记录的键，
Jev 读英文聊天一样准。

## 安装

1. 从 Releases 页下载 APK，或在 GitHub Actions 最近一次成功的「Build」里下载 `vibecheck-debug-apk`，
   或自己编译（见最后的「开发」）后把 `app/build/outputs/apk/debug/app-debug.apk` 传到手机安装。
2. 打开 App，在「设置」页填 TypeSafe API Key，点「测试」确认能通；要用深思 / 回复 / 学习此人，再填 OpenRouter Key。所有改动自动保存。
   **没有 TypeSafe Key？** OpenRouter 上也有 Jev：判断引擎选「Jev，走 OpenRouter」，一个 OpenRouter Key 全搞定。默认仍走 TypeSafe 自己的接口。
3. 页面最上面的「开始使用」清单会告诉你还差什么。点「打开无障碍设置」，开启「Vibecheck 读空气」。
   **开关是灰的**：Android 13+ 对侧载应用有「受限设置」保护。
   点清单里的「应用信息」→ 右上角 ⋮ → 允许受限设置 → 验证锁屏密码，再回来开启。
4. 进聊天页，右边缘出现小气泡。对方发来消息后约 0.5 秒气泡变色；点气泡看卡片。

**从 6.5 或更早版本升级：** 如果升级后「学习」不会自动翻页，把无障碍服务关掉再打开一次，让系统拿到新的手势权限。

## 应用界面：设置 + 工具

应用有三个标签页，改动随手自动保存：

- **设置**：上手需要的东西：开始使用清单、判断引擎和 Key、模型（每个选项都写着擅长什么）、监听哪些应用、几个行为开关（启用解读、自动深思、成人回复、截图识字、从走向学习、记住每个人）、给没单独写过背景的人用的通用背景。
- **人物**：记住的每个人。卡片上有名字（或名字的 emoji 小图）、应用、Ta 是你的什么人、学了多少条、档案里的一句话。点进去是 Ta 的专页：
  - 关系和亲近程度；
  - 分段的档案；
  - 边聊边学到的：话量、你对 Ta 的说话方式、哪些做法让气氛缓和、哪些更僵；
  - 在这里改名字和专属背景；
  - 暂停、和别的应用上的 Ta 合并、重新截名字图片、删除聊天记录存档、忘记。
- **工具**：其他功能，每个一块简单的卡片：**暂停**（1 小时，或到明早 8 点）、**卡片**（字号、卡片上显示哪些按钮、高风险振动、气泡位置）、**用量**（每类调用今天和累计的次数、token 和花费）、**备份**（把人物记忆导出成文件 / 导入，不含 Key）、**保持运行**（电池优化和应用信息的快捷入口）、**诊断**（运行状态、上次出错的时间和位置、调试模式、局域网排查接口）、**使用说明**。

每块卡片右上角都有「隐藏」。隐藏的会收到工具页最下面，点一下就恢复（或「全部恢复」），界面上只留你用得到的。

不需要「显示在其他应用上层」权限：卡片用的是 `TYPE_ACCESSIBILITY_OVERLAY`，
无障碍服务自带，属于受信任窗口，不会被 `setHideOverlayWindows()` 挡掉，也不会触发
Android 12+ 的 untrusted-touch 拦截。

## 学习（单步 contextual bandit）

Jev 是托管模型，没有梯度可以回传，所以「学习」发生在应用这一侧，用的是手机上真的能观察到的东西：

- **上下文** = 这一轮判断出的 `intent`
- **动作** = 卡片上排在最前面的 `action`
- **回报** = 下一轮的危险等级比这一轮低了多少（缓和为正，升级为负）

两个产物：

1. `dangerBias`：这段关系专属的危险等级校准。模型对这个人系统性高估或低估时，卡片上的数字会跟着修正。
2. 每个 `intent|action` 的平均回报：样本满 3 次后开始重排「最佳动作」。
   经验把排第一的动作换掉时，卡片底部会出现「已按你们过去的走向调整」。

只有在「上一次给了建议 → 你确实回了消息 → 对方又回了」这条完整链路上才记一次；
对方连发两条不算，因为那说明不了建议的好坏。

**这是相关性，不是因果。** 应用看得到「建议显示之后发生了什么」，看不到你有没有照做。
要因果就得让卡片可点、只对「采纳」的建议记分，代价是卡片会挡住微信的触摸。
模型状态存在 SharedPreferences，可随时清空。

## 卡片怎么用

**平时只有一个小气泡。** 进微信/Soul 的聊天页，右边缘出现一个小圆点，聊天内容一点不被挡。
判断照常每条新消息跑，对方连发几条时等停下来一起判断一次；往上翻看旧消息不算新的一轮，卡片保留最新那一轮的判断。结果只体现在气泡上：显示翻车风险的数字，颜色按风险变（绿→黄→红）。
**点气泡才展开卡片**，✕ 收回气泡。**拖动**气泡可以换位置（松手吸到最近的边，下次还在那里）；**长按**气泡打开菜单。
卡片跟随手机的深色模式，也不会挡住键盘。

卡片可以点（无障碍悬浮窗是受信任窗口，点卡片不会挡住微信收触摸，点卡片以外的地方照常传给微信）。
卡片顶部写着这是谁、什么场合，认错人一眼就能看出来；打分类的回答带上含义（「3 / 4 · 今天」「5 / 6 · 很危险」），不只是一个数字。

| 按钮 | 做什么 |
|---|---|
| 展开 / 收起 | 展开会多显示「这是什么场合」「需要马上回吗」，并把深思结果完整铺开 |
| 深思 | 调 OpenRouter 上的 DeepSeek 做一次深度分析：对方在意什么、最容易踩的坑、下一步怎么做 |
| 回复 | 先用一句话判断局面（轮到谁、往哪走），再按**你自己的说话方式**起草三条不一样的回复；最后一句是你说的时，给的是追发，或者直接建议先等等。点一条直接填进（空的）输入框，长按复制。永远不会替你发送 |
| 学习 | 把和这个人的全部聊天记录翻一遍存下来，写一份详细档案（见下面「学习此人」） |
| ⋯ | 重新判断、关系（Ta 是你的什么人、有多亲近）、改名、暂停 1 小时、这个聊天不再解读、设置 |
| ✕ | 收起卡片，右边缘留一个小圆点，点圆点再叫回来 |

深思、回复、学习和 ⋯ 都可以在「工具 → 卡片」里单独关掉。深思结果和回复草稿是两个独立的区块，
后到的不会冲掉先到的。卡片上任意一行长按即可复制。

深思和回复**只在你按下时才调用**，一次约 $0.0002 到 $0.001。每来一条新消息只跑 Jev，几百毫秒、便宜。
想让值得细看的轮次自动深思，可以在「设置 → 行为」里打开（默认关，每次都要花钱调用模型）；打开后气泡显示 ✦ 表示有内容可看。

每个聊天有自己的卡片：切到别的聊天再切回来，上一次的判断还在，不会重复花钱。
调用失败（没网、Key 被拒）会写在卡片上并逐步延长间隔重试；Key 被拒则在你改 Key 之前不再重试。

**暂停。** ⋯ → 暂停 1 小时（或「工具 → 暂停」）让所有聊天都不解读，到时间自动恢复。
⋯ → 这个聊天不再解读：对这个人既不解读也不记录，直到你在卡片上或「人物」页里恢复。暂停时气泡显示 ⏸。

**两个模型，在「设置 → 模型」里选：**
- **深思和学习**（默认 `deepseek/deepseek-v4-pro`）：先想一想再写。
- **回复和看图**（默认 `moonshotai/kimi-k2.6`）：写回复草稿，不先想，直接写。截图识字的聊天（微信、Telegram）顺手截的图也交给它看，
  因为 OCR 读不到表情包和表情符号，而那恰恰是中文聊天里情绪最重的部分。Kimi K2.6 是 EQ-Bench 创意写作榜上开源模型的第一名，中文是母语。

每个模型都是一列选项，写着各自擅长什么，点一下就用：
- 回复：Kimi K2.6（又快又会写）、Kimi K3（写得最好，创意写作榜全球第二，仅次于 Claude Opus 5；慢一些、贵一些）、DeepSeek V4.1 Flash（最快最省）、通义千问 3.8 Max（中文语感最自然；阿里的接口会过滤内容，不写成人回复）。
- 深思和学习：DeepSeek V4 Pro、Kimi K3、通义千问 3.8 Max。

「其他模型…」可以填任何 OpenRouter 模型名。不能看图的模型，本来要附截图时只发文字。

回答是边写边显示的：判断和第一条草稿先出来，后面的接着出。每次调用都走 OpenRouter 上这个模型最快的服务商
（模型名带 `:nitro`、`:floor` 之类的按它自己说的走）。两个模型各有一个「测试」按钮，会告诉你用了几秒。

**成人内容（18+）** 默认关，在「设置 → 行为」里打开。打开后，Ta 已经在聊性、明显在调情并且乐在其中，
或者你们是恋人、以前就这样聊过时，草稿可以同样暧昧、大胆甚至露骨。尺度跟着对方走，不会比 Ta 表现出来的更进一步；
Ta 说不、犹豫、岔开话题，或者有一点可能未成年，就完全不写。

## 一直在学，哪怕卡片关着

判断要花钱，观察不要。所以只要你在被监听应用的聊天页，不管卡片是收起的、✕ 掉的，还是
「启用解读」整个关掉，它都照样读屏、认人、把新消息记进这个人的档案；只是不调模型、不画卡片。

被动积累的东西（全部本地，不上传原文）：

| 学到什么 | 怎么来的 |
|---|---|
| 我对这个人的说话方式 | 只统计我自己发的：平均字数、表情率、问句率、道歉率 |
| 谁先开口 | 静默超过 2 小时算新一轮对话，看这轮第一条是谁发的 |
| 话量比 | 双方条数和平均长度 |
| 我多久回一次 | 从「对方消息出现」到「我的消息出现」的间隔，只统计观察到的那些 |
| 高风险轮次占比 | 真正判断过的轮次里，危险等级高的有多少 |
| 聊过多少天 | 去重的日期数 |

这些会作为「这段关系的长期观察」进深思的提示里。判断只拿谁先开口、我多久回、高风险占比和聊过多少天，不拿条数和长度：那些每来一条消息就变，对判断这一轮也没有更多帮助。
每条消息只计一次：每一屏都和这个人最近已计数的消息对齐（容忍 OCR 偶尔认错一个字），
所以停在同一屏、往上翻历史再翻回来，都不会把数字刷上去。谁先开口、我多久回这类跟时间有关的统计，
只取在你看着聊天时新到的消息。想关掉就在「设置」里关「在聊天里顺便记住每个人」；暂停了的聊天永远不记录。

## RL 不再只有一层

以前的 arm 是「意图 → 动作」。现在每次结算同时更新三层，查的时候从最细的一层往回退：

```
恋人或伴侣|在表达不满|先道歉         ← 有 3 次以上就用它
*|在表达不满|先道歉                 ← 换个场合，退到「这个意图下」
*|*|先道歉                          ← 全新意图，退到「这个动作一般怎么样」
```

好处是新场合不用从零开始；代价是刚开始会用比较粗的经验。同一个动作在不同场合可以有相反的评价，
所以「先回应情绪」对某人在吵架时是对的，在闲聊时可能是多余的，两个格子各记各的。
人和人之间**仍然完全不共享**。

## 人物记忆（全部在手机上）

应用从聊天页标题栏认出对方是谁（认不出就退回头像的 contentDescription「XX头像」），
然后所有东西都按「应用包名 + 名字」分开存。名字里有 emoji 没问题（应用给出文字时）；但截图识字（微信、Telegram）完全看不到 emoji：
- 名字只有 emoji 的聊天按对方消息旁的头像认人（看头像中间的颜色）。屏幕上只有你自己的消息时看标题栏里的 emoji：只和一个人的对得上才算是 Ta；都对不上，就看屏幕上的消息是不是接着刚才那个聊天，再对不上就不猜。
- 这样的人就用那个 emoji 本身来标：从聊天标题栏截下来的名字小图，显示在卡片和「人物」页里，不会显示成一串代码。
- 真正的名字（带 emoji 的文字）从 Ta 的消息通知里自动拿：通知里那条消息出现在这个聊天里时，通知上的名字就记给这个人。
  OCR 只读出一半的名字也会补回 emoji（「李四」变成「李四🌸」）。
- 卡片 ⋯ → 改名 可以手动起名（能输入或粘贴 emoji），你起的名字优先。
- 对方正在输入时标题栏显示的「对方正在输入...」不会被当成名字。
- 应用给所有人都用的标签（Soul 每个头像上的「Souler」、对方、用户）不会被当成名字；只由符号组成的名字（「...」「。」）在能读到文字的应用里照样认。
  调试模式会列出标题栏上的文字和头像描述，名字为什么认对或认错一看就知道。

| 存什么 | 怎么来的 | 用在哪 |
|---|---|---|
| 关系 | 「学习此人」得出，或在卡片 ⋯ → 关系、「人物」页里手选 | 作为 `我和对方的关系` 进入 state，这时不再问「什么场合」。还不知道、但连续五轮答得一样时也先不问，每十二轮再问一次 |
| 亲近程度 | 同上，单独选：不熟、普通、熟、很铁、无话不谈 | 作为 `我们有多亲近` 进入 state，也显示在卡片标题上 |
| 你起的名字 | ⋯ → 改名，或「人物」页 | 到处显示这个名字，也是告诉模型的名字 |
| 专属背景 | 你在设置里手填 | 和档案一起作为 `关系背景`，两者都取代通用背景 |
| 我对这个人的说话方式 | 统计你自己发出的消息：平均字数、表情率、问句率、道歉率 | 给深思和回复草稿（判断看的是对方这一轮） |
| 最近 8 轮走向 | 每次判断后记一条「意图/危险/动作」 | 最近 3 轮作为 `我们最近几轮的走向` 进入 state |
| 这个人专属的 bandit | 见上面的学习一节 | 校准危险等级、重排最佳动作 |
| 聊天记录存档 | 「学习此人」读到的全部聊天，之后边聊边自动补上新消息 | 写档案的材料；回复草稿从里面挑你以前的真实回复 |
| 档案 | DeepSeek 读完整段存档后分段写的 | 完整档案给深思和回复；精简版作为 `关系背景` 给判断；卡片上显示最相关的一条 |

同一句话对不同的人不是一个意思，所以两个人之间的学习**完全不共享**：对 A 有效的「先道歉」
不会影响对 B 的排序。「人物」页里可以搜索、查看每个人学到了什么、改专属背景、暂停、
和别的应用上的同一人合并、或者忘掉某个人；「工具 → 备份」可以把全部记忆导出成文件，换手机时导入。

### 学习此人

在一个聊天页打开卡片，点「学习」。卡片收成气泡，气泡上显示已读条数，应用自己往上翻完**你们的全部聊天记录**，
大约一秒一页（要截图识字的应用稍慢）。每页把新看到的消息接到前面（按页与页的重叠部分对齐，不是按文字去重，
所以「嗯」发三十次算三十条），翻到第一条消息为止（连续五页没有新内容）；中途点一下气泡就停，已读到的照样用。
读的时候别离开这个聊天；读记录和写档案期间屏幕会自己保持常亮，因为锁屏后 Android 会断掉后台应用的网络。

读到的存在手机上（应用私有目录，每个聊天一个文件），之后边聊边自动补上新消息。再点「学习」只往上读到存档衔接的地方，几秒钟就好。
在「人物」页 Ta 的专页里可以删除存档；忘记这个人也会一起删掉。

然后写档案。长的聊天记录按每段约 12000 字分批发给你设置的 OpenRouter 模型，三段同时：先给每段写笔记，再把所有笔记合成一份档案。
笔记按内容缓存、写好一段存一段，以后再学习只为新增的部分付费。卡片上会显示进度：第几步、已整理几段（进度条）、用了多久、预计还要多久，几秒刷新一次；应用里这个人的页面也能看到。十分钟没有任何进展会提示「好像卡住了」，这时再点「学习」会重新开始，已写好的段落不会重做。应用里这个人的页面也可以直接用存的记录重新分析，不用打开聊天（只更新变了的段落，或者换模型后全部重做）。一个模型出错（忙、挂了、拒绝回答）时，会自动换「设置」里的另一个模型再问一次。网络断了会隔一会儿重试；还是断了的话，回到这个聊天会自动接着写。档案开头写明 Ta 是你的什么人、有多亲近，
然后分段：Ta 是谁、我们怎么相处、Ta 怎么说话、我怎么跟 Ta 说话（都附原话）、Ta 喜欢、Ta 不喜欢、常聊的事、我们的梗、
重要的事、雷区、Ta 难过时。话量和说话方式按全部记录重算，当前卡片（同一段消息）按学到的东西重新判断一次。

用在哪：判断拿到精简版（相处方式、说话方式、雷区、难过时）；深思和回复草稿拿到完整档案；回复草稿还会带上最多 8 段你以前对 Ta 的真实回复
（和 Ta 刚说的话最像的几段，加上最近的几段）以及你最常说的话，所以写出来像你本人，不是模板。卡片上合适时会多一行档案里的提示：
Ta 需要安慰时什么有用、可能翻车时的雷区、开玩笑时你们的梗。

读完后聊天停在很靠上的旧记录，这些旧页面不会被拿去判断，等你翻回最新的消息再继续。中途切走聊天、切换页面、服务被打断都会中止。

### Ta 是你的什么人

分成两件事：Ta 是你的什么人，以及你们有多亲近。关系好不等于是恋人，以前的选项「恋爱或亲密关系」把两者混在了一起。

每个人可以带一个关系：恋人或伴侣、暧昧、朋友、家人、同事、客户、陌生人、客服，和 `situation` 的选项一样；
再带一个亲近程度：不熟、普通、熟、很铁、无话不谈。知道了关系，就直接告诉 Jev，不再问它，所以每条消息都按这个关系判断，不会因为你们在聊对方的男朋友，就把好朋友判成恋人。
不知道时，这个问题问的是你们两个人的关系，不是聊天话题，也不再默认是恋爱。

两者都由「学习此人」填上（档案前两行），也可以在卡片 ⋯ → 关系、或「人物」页里手选；手选的不会被之后的学习覆盖，选「自动判断」「不确定」就交还给学习。
6.7.0 之前写的档案，第一行说得清楚的，会直接从里面读出关系和亲近程度（「好友或死党，关系亲密」读成 朋友 · 很铁），不用重新学习。
关系、亲近程度、名字、档案或专属背景一改，这个聊天的卡片会重新判断一次，刚学到的结果留在新卡片下面。

### 关于我（跨所有聊天学你）

除了学每个人，应用也会学**你自己**，跨所有聊天（「设置 → 行为 → 了解我」，默认开）：
- **每天的记录**：任何一个监听的聊天里，实时出现的消息（你的和对方的）按天记在手机上，带时间和是哪个聊天。聊天隔了一阵才打开、只是看起来是新的那些不记。
- **每天的小结**：过完一天，由深思模型写成几行：你做了什么、去了哪、和谁聊了什么、定了什么计划、心情怎么样。点「总结今天」可以马上写今天到目前为止的。
- **关于你的档案**：每学习一个人，也会从你们最近的聊天里挑出关于你的事（按段缓存，和学人一样）。再加上最近每天的小结、你身边的人，合成一份关于你的档案：你是谁、你怎么说话（具体到能照着模仿，对不同的人有什么不同）、喜欢什么不喜欢什么、最近在忙什么、在意什么、身边有哪些人。自动整理时，一个聊天最新的那段长到一倍半才重新整理，材料都没变就不重写；点「整理关于我的档案」总是从全部材料重写。

它显示在「人物」页最上面的「我」。点进去有：
- 关于我的档案，分段显示；
- 每一天的小结；
- 你在各个聊天里的说话方式；
- 重新整理和清空的按钮。

回复草稿和深思会带上它的简版：你怎么说话、你是谁、最近在忙什么、喜欢什么、最近三天、今天在别的聊天里说过的话。所以草稿能用你自己的话说出「刚下班」这类你今天真的做过的事。模型只能用写着的，不能编。

### 跨应用同一人

微信上的「小李」和 Messenger 上的「Sam」是同一个人时，在「人物」页点小李 → 更多 →
「和另一个人合并」，选另一个。话量、说话方式、最近走向、档案和 bandit 都并进去
（arm 合并样本，危险偏置按各自学习次数加权），之后在哪个应用打开都用同一份记忆。

统计只在本地做，但摘要（例如「平均 12 字，道歉 8%」）会随判断请求一起发给模型。
原始聊天记录只在两种情况下存在手机上：学习过的人的聊天记录存档，和「了解我」的每天记录。
发出去的只有这些：判断、深思、回复要用的那部分，以及写档案、写每天小结时交给模型的内容（见下面「隐私」）。

## 运行中排查

在「工具 → 诊断」里打开「局域网排查接口」后，同一 Wi-Fi 的电脑可以直接读运行时状态，不用 adb、不用重启：

```
curl "http://<手机IP>:8848/status?t=<口令>"
```

| 路由 | 内容 |
|---|---|
| `/status` | 服务是否连上、当前前台应用、最近一次扫描结果、最后一个错误、待结算的学习回合 |
| `/log` | 最近 200 条运行日志（事件、请求耗时、学习更新） |
| `/tree` | 当前界面完整节点树：class / id / text / desc / 可长按 / 坐标 |
| `/last` | 最近一次发给 TypeSafe 的请求体和原始响应 |
| `/learn` | 学习到的偏置和每个动作的平均回报 |
| `/windows` · `/shot` | 当前窗口列表 · 截图是否可用（排查 OCR 路径） |
| `/learn/reset` | 清空学习状态 |
| `/rescan` | 强制重新判断当前这条消息 |

口令在应用里生成，每个路由都要带；点「换口令」后旧地址立即失效。只回应局域网里的请求（私有、链路本地、
IPv6 唯一本地地址），手机在移动网络上拿到公网 IPv6 也不会对外开放。接口默认关闭。
**`/tree` 和 `/last` 会原样吐出聊天内容**，查完请关掉。

`/tree` 就是用来回答「微信到底有没有打乱节点」的：把它和屏幕上真实的文字对一眼就知道了。

## 已知限制

- **微信 8.0.52 起会对第三方无障碍服务打乱节点内容**（ids、文字每次快照都不一样）。
  应用会退回到截图识字（OCR）；这条路读不到表情和表情包，所以深思会附上截图。
  拿不准时先开**调试模式**或看 `/tree`。
- **Telegram 的气泡是画在 canvas 上的**，节点树里没有文字，和微信一样走截图 OCR。
- OCR 用的是 Google Play 服务的本地文字识别，第一次使用时下载模型。没有 Play 服务的手机（很多国行手机）
  走不了 OCR 这条路，错误会显示在「工具 → 诊断」里。Android 14+ 截的是聊天窗口本身，打开的卡片和键盘都不会挡住 OCR。
- OCR 偶尔会把一个字认成形近字（比如「好啊」认成「好响」）。读屏幕文字的模型都会被告知这一点：按聊天的意思理解这种字，写草稿、引用原话时写原本的字。
- 谁说的靠位置判断：气泡贴左是对方，贴右是自己。长消息几乎占满一行时两边看起来一样（微信最宽的气泡左右留白相同），
  这时看文字旁边画的头像或气泡离哪边的屏幕边缘更近；节点树里看和它同一高度的头像。链接卡片下面几行跟着标题走。
  Soul 没有公开的节点结构资料，换版本可能需要调整。
- 各应用在消息列表里印的状态字（Seen、Delivered、SMS · Now、Active now、通话记录如 已取消 / 对方无应答 / Canceled、
  语音秒数（连带被读成「3" ((」的声波图标）、表情回应）按已知样式过滤，漏网的会混进上下文。
- 回复上下附带的引用（「名字：…」）不算消息，不管引用的是谁的话。认引用靠四样：
  - 名字：Ta 的名字，或者 Ta 引用你时显示的你的名字（应用会按应用分别记住）；
  - 读不出来的名字（emoji）；
  - 引用的图片（「名字：[图片]」）；
  - 内容和屏幕上或最近存下的某条消息一样。
  Messenger、Instagram 的「Sam replied to you」和它下面那条淡色的原消息也不算。旧版本当成消息存下的引用，读取存档时会去掉。
- 识别完全不依赖 view id（微信每个版本都会改名），只用：TextView + 文字 + 屏幕坐标 + 是否可长按。
- 判断只看**屏幕上可见的**消息，最多取最近 12 条；深思和回复最多看 30 条，学习过的人会从存档里补上屏幕之前的记录。只有你学习过的人才会读取并保存完整聊天记录。
- 这些不管写着什么都不算消息：并排的一排短字（Soul 输入框上方的快捷回复 下午好 / 礼物 / 桌球 / 比心 / 猜拳、工具栏、表情回应）、
  输入框及以下的一切（发送按钮、正在打的字，键盘推上去也一样）、标题栏里的字（返回键上的未读数、Soul 的「加速」）。
- 学习读的是聊天里能读成文字的内容：图片、表情包、语音、文件都不在里面；一长串图片可能被当成已经翻到顶而提前结束（再点一次「学习」会接着读）。
  不用微信自己的搜索和日期，所以存档里没有时间。
- 国产 ROM（MIUI / ColorOS / 鸿蒙）会杀后台无障碍服务，需要手动关掉省电优化（「工具 → 保持运行」）。

## 隐私

只读「设置 → 在这些应用里解读」里勾上的应用，而且只在它正显示在屏幕上时读；取消勾选的应用从那一刻起就不再碰，正开着的聊天也一样。

监听的应用发出的通知只读取发送人和消息，存在内存里（最近 40 条），只用来认出名字是 emoji 的人，不保存、不发送。

聊天文本会发到 `api.typesafe.ai`（选了 OpenRouter 引擎则发到 `openrouter.ai`）。**学习某个人会把你们的全部聊天记录发给你的 OpenRouter 模型**来写档案，
回复草稿会带上几段你们以前的对话。开着「了解我」时：
- 每个监听的聊天里说的话会按天在手机上存 90 天；
- 每天的记录会发给深思模型写小结；
- 回复草稿也会带上你今天在别的聊天里说过的话。

可以关掉，也可以在「我」的页面里全部清空。API Key 和学习状态存在应用私有 SharedPreferences 里；聊天记录存档是应用私有目录里的文件，不包含在备份导出里。
排查接口只在局域网，且每个请求都要口令，但它能读出聊天内容，别在公共 Wi-Fi 上开。
这是自用工具：只在你自己的手机、自己的对话上用。

## 开发

需要 JDK 17 和 Android SDK（API 35）。仓库带 Gradle wrapper，固定 Gradle 8.9（校验 SHA-256）：

```bash
ANDROID_HOME=~/android-sdk ./gradlew --no-daemon testDebugUnitTest assembleDebug
```

每次 push 和 pull request，GitHub Actions 都会跑同样的命令并上传 debug APK。

**发版。** 改 `app/build.gradle.kts` 里的 `versionCode` / `versionName`，在 `CHANGELOG.md` 里加上这个版本的一节，
合并到 `master`：Release 工作流发现这个版本还没发布，就会跑测试、编译 `vibecheck-<版本>.apk`，并以那一节为说明发布。
推送标签 `v<versionName>` 或手动运行工作流也可以（会替换已有版本的 APK）。

**签名。** 从 6.7.1 起所有版本都用同一个签名 `app/signing/release.p12`，新版可以直接覆盖安装旧版。这个文件是加密的
（AES-256，密码是一串很长的随机字符），没有密码就没用；密码是仓库 secret `RELEASE_KEY_PASSWORD`。没有这个 secret，
Release 工作流就不发布（不会发出一个没法覆盖升级的 APK），发布前还会核对 APK 的证书（SHA-256 `d364f1fb…29f1b017`）。
本地想编出同样签名的包，在环境变量里设 `RELEASE_KEY_PASSWORD`；不设的话 `assembleRelease` 用 debug 签名，装不到正式版上面。

`Chat.kt`、`Jev.kt`、`Person.kt`、`Relation.kt`、`Learner.kt` 不依赖 Android：气泡识别、系统消息过滤、
两步判断的问题集、卡片渲染、bandit 更新与合并、翻页对齐，以及防止被动统计重复计数的对齐，都在 `app/src/test/` 下有单元测试。
